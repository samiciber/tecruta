Los nombres indican el viewport CSS de revisión. El proveedor de capturas puede reducir ligeramente la resolución del JPEG. Se descartó una captura incompleta de la recarga; la persistencia se verificó en el estado accesible del navegador y en las pruebas de integración.

Rutas de revisión: http://127.0.0.1:5201/ para tienda y http://127.0.0.1:5202/resenas para moderación. Los accesos efímeros se consultan únicamente en http://127.0.0.1:5201/revision-local mientras esté activo el lanzador.
